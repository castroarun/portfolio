# Brain Dump - Arun's Knowledge Base

This is your personal knowledge repository that powers the AI-assisted resume chat.

## Structure

```
brain-dump/
├── career-stories/       # Detailed project narratives, memorable moments
├── achievements/         # Awards, recognition, metrics, wins
├── challenges-solutions/ # Situational awareness - problems & how you solved them
├── personal-interests/   # Hobbies, passions, what drives you
├── technical-expertise/  # Deep dives into your technical knowledge
└── index.json           # Structured metadata for AI search
```

## How to Add Content

### Option 1: Through Claude Code
Type `/dump` in any conversation to enter brain dump mode. Claude will ask you structured questions and save your answers.

### Option 2: Direct Edit
Edit the markdown files directly. Use the templates in each folder as a guide.

## Content Guidelines

- Be specific with numbers and metrics
- Include the "why" not just the "what"
- Add context about challenges faced
- Include learnings and reflections
- Write as if explaining to someone who knows nothing about the project
