## The Challenge
Needed to build a full-scale, lightweight Java-based utility for cash denomination handling that could:
- Support multiple screens
- Handle multiple currencies
- Provide dynamic pagination
- Seamlessly integrate with the underlying product UI workflows
- Be highly reusable across implementations

## What Made It Exceptional
- **Zero Java Knowledge**: Had no prior Java experience when starting
- **No Internet Access**: Could not Google solutions or reference Stack Overflow
- **No AI Assistance**: Pre-ChatGPT era - pure self-learning from books/documentation
- **Production Quality**: Built something robust enough for Tier-1 bank production use

## The Solution
Built a multi-screen, currency-aware, dynamically-paged Denomination Module that:
- **Data Structure**: Used TreeMap for efficient currency/denomination sorting and lookup
- **Architecture**: Pre-compiled Java classes (executables) instead of runtime coding - made it significantly faster
- **Integration**: Simple API - a single Java method with parameters that existing source code could call
- **Deployment**: 95% reusable via source deployment + API integration
- Integrated seamlessly with Finacle UI screens
- Supported end-to-end workflow integration
