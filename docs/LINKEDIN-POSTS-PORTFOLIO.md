## Post #1: The Digital Resume

**Hook:**
What if a resume could answer your questions?

**Body:**
This isn't a PDF. It's a digital resume.

What makes it digital:
- **Interactive skills visualization** - Filterable progress bars, radar chart
- **Professional timeline** - Visual career journey with photos from key milestones
- **AI Chat Assistant** - Ask it anything about experience, skills, or projects
- **Live GitHub stats** - Contribution heatmap, repository cards, real commit data
- **One-click PDF download** - A condensed derivative of the same data, traditional format for offline use

The chat widget sits in the corner. Type a question like "What's your tech stack?" or "Tell me about your testing philosophy" - it responds instantly from a knowledge base of 60+ pre-written answers.

Can't find what you're looking for? Unanswered questions trigger an email notification via Supabase edge function - so I'll know exactly what recruiters are asking that my knowledge base doesn't cover yet.

The bonus: I can train the assistant directly from the browser. Type a keyword command and add new responses on the fly - no code deployment needed.

Try it: [link to resume]

## Post #2: The Self-Fitting CV

**Hook:**
A CV that adjusts itself for different roles.

**Body:**
Remember the browser-based training from the digital resume? The same concept extends to the traditional CV - but with a twist.

The flat CV has a content automation system built in. Natural language commands adjust the content:

```
Add TypeScript at 85%
Update bullet 1 in Bank of America to: Led migration achieving 50% efficiency
Review my resume for Principal Architect role
```

The system validates every edit:
- Action verbs scored (30 pts)
- Metrics presence checked (40 pts)
- Impact clarity rated (20 pts)
- ATS keyword compliance verified

Low-scoring content gets auto-suggestions. The CV self-corrects toward industry best practices.
